# המשפטון ⚖️

כלי ווב להכנת נספחים משפטיים לפי **הוראת מנהל בתי המשפט בדבר צורת מסמך ומבנהו (כ"ו תמוז תשפ"ה)**.

## מה זה עושה

מקבל קבצי PDF ומייצר קובץ PDF מוכן להגשה לבית משפט, הכולל:

| שלב | תוכן |
|-----|------|
| 1 | כתב טענות (אופציונלי, עם/בלי מספור עמודים) |
| 2 | מסמכים נוספים לפני תוכן העניינים — תצהיר, ייפוי כוח... |
| 3 | **תוכן עניינים לנספחים** (נוצר אוטומטית) |
| 4 | נספחים — כל אחד עם דף מקדים + תוכן |

**עומד בדרישות**: גופן David, שוליים 2.5 ס"מ, מיספור נספחים בספרות עבריות (א׳, ב׳...), 36pt בדף המקדים, מיספור עמודים רצוף.

## הרצה מהירה

```bash
pip install -r requirements.txt
bash run.sh
# → http://localhost:5050
```

> **macOS בלבד**: WeasyPrint דורש `DYLD_LIBRARY_PATH=/opt/homebrew/lib` — `run.sh` מטפל בזה אוטומטית.

## גופן David (חובה לציות מלא)

הכלי כולל את **Frank Ruhl Libre** (open-source, Google Fonts) כברירת מחדל.  
לגופן **David** המקורי (המומלץ על-ידי הוראת מנהל בתי-המשפט):

1. מצא את הקובץ בתוך Microsoft Word:  
   `/Applications/Microsoft Word.app/Contents/Resources/DFonts/`
2. העתק את `david.ttf` ו-`davidbd.ttf` לתיקיית `fonts/` בשמות:
   - `David-Regular.ttf`
   - `David-Bold.ttf`

## פיצ'רים

- **שמירת פרויקטים** — חזרה לעריכה בכל עת
- **גרירה לסידור מחדש** — כל קובץ ניתן להזזה
- **החלפת קובץ** — ניתן להחליף PDF בלחיצה אחת
- **מספור סלקטיבי** — לכתב הטענות בנפרד משאר המסמכים
- **אפליקציית Mac** — ראה `scripts/build_app.py`
